# Design system

The application is an operational school workspace. White surfaces, structured blue navigation, concise tables, and generous spacing keep circulation tasks clear. The school crest is the visual anchor; gold appears only as a small accent. Desktop management uses a sidebar and tables; mobile uses a drawer and compact cards. The Issue / Return control remains prominent.

## Tokens

Background `#F6F8FB`; surface `#FFFFFF`; primary blue `#0276B5`; deep blue `#083993`; text `#1F2937`; muted text `#64748B`; border `#E5EAF0`; success `#127A58`; warning `#986700`; danger `#B42338`.

Typography uses Manrope for headings and DM Sans for body text. Cards use restrained 12–14px corners and a soft offset shadow. Forms and scanner controls use large touch targets and visible focus rings.
