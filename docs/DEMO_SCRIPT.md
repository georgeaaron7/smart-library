# Five-minute demonstration

Prepare a librarian account, run `supabase/seed.sql`, and use mock email mode. Print one demo student card and one copy label. Use HTTPS for a phone camera.

1. **Login** — Show the school crest, librarian-only sign-in, and password reset link.
2. **Dashboard** — Point out live counts, due soon, overdue, recent activity, and popular books.
3. **Student** — Add a fictional student with guardian email, open the record, and print its QR card.
4. **Book** — Scan or enter an ISBN. Review Open Library metadata, set copy count to two, then save. Open the title and print both unique QR labels.
5. **Issue** — Scan the student card and one copy label. Show the due date, rules, and issue confirmation.
6. **Return** — Switch to Return, scan the same copy, and confirm. Show recommended next books.
7. **Reminders** — Open Overdue, send a reminder for a demo loan, then open Activity to preview the simulated email.
8. **Recommendations** — Select a seeded student with reading history. Explain that subject, author, class suitability, popularity, and available copies determine each suggestion.

If camera access is unavailable, use the manual code fields in the scanner. The workflow stays inside the application.
